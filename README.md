Vulnerable Flask App for SAST Testing
This repository contains a deliberately vulnerable Python web application built with the Flask framework. It is intended for educational purposes and for gaining experience with Static Analysis Security Testing (SAST) tools.

Purpose
The primary goal of this project is to provide a "broken" codebase that SAST tools can scan to identify common security flaws. It includes classic vulnerabilities to give educational experience finidng and fixing sast issues.
